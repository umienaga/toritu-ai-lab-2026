# Design Thinking Workshop

東京都立AIラボ 中級ワークショップ「デザイン思考講座」の学習記録です。

## テーマ
東京の通学体験を再デザインする

## 学んだこと

- デザイン思考の基本プロセス
- ペルソナ・共感マップ・ジャーニーマップ
- How Might Weによる課題定義
- アイデア創出
- プロトタイプ作成
- Like / Wish / Willによる振り返り

## 成果

チームで「電車内の匂い」をテーマに課題を設定し、  
匂いを投票・共有できるアプリを企画しました。  
デザイン思考のプロセスを通して、課題発見からアイデア創出、プロトタイプ作成までを経験しました  

## 学び

デザイン思考では、
「どういう技術を使うか」ではなく、

「誰が、何に困っているのか」

を最初に考えることが重要だと学びました。

## 自分が取り組んだこと

- チームで出たアイデアを整理し、見える形にまとめました。
- 「匂いの問題をどう断つか」という視点で議論に参加しました。
- 当初は個人で対策する案を考えていましたが、議論を通して「匂いの原因との間を仕組みで切り離す」という発想へ変化しました。
- チーム活動では、自分の意見に固執せず、より良い案を取り入れる難しさを学びました。
